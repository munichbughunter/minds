1//! Der Reader — die Oberfläche für v0.1: eine statische Seite über den Kontext.
2//!
3//! Das ist der Moment, um den es in der Vision geht: **auf eine Zeile klicken
4//! und den Prompt dahinter sehen.** Alles in diesem Crate dient diesem einen
5//! Satz.
6//!
7//! # Zustandslos, mit Absicht
8//!
9//! Der Reader hält keinen Zustand: Er liest bei jedem Lauf Git und Store, baut
10//! einen [`Index`] und schreibt HTML. Kein Dienst, keine Datenbank, kein
11//! Betrieb — „Ref fetchen, JSON parsen, rendern" (Architektur-Prinzip 6). Damit
12//! ist die Seite trivial deploybar: ein Verzeichnis, das jeder Webserver
13//! ausliefert, oder eine `file://`-URL im Browser.
14//!
15//! # Der Schnitt: I/O dünn, Logik rein
16//!
17//! Nur [`Index::build`] fasst Git und Store an. Alles Weitere — der Join von
18//! Blame und Sessions, die Zusammenfassung, das Rendern — sind reine Funktionen
19//! über einfache Daten und damit ohne Repository testbar, genau wie in
20//! `minds-core`.

⚠ vermutet — heuristisch verknüpft, nicht über einen Trailer belegt

Absicht

Ich möchte M5 so umbauen, dass wir es genauso machen wie entire! Mit dem Hook-Ansatz. Wir bleiben erst einmal bei der Rust implementierung. Diese ist effizienter. Das ist der entscheidende Unterschied. Minds soll auch Hooks installieren im Agenten selbst: Claude Code über `.claude/settings.json`, Codex über `.codex/hooks.json`, Cursor über `.cursor/hooks.json`, Gemini über `.gemini/settings.json`, OpenCode über ein TypeScript-Plugin. Bei Codex wird zusätzlich `codex_hooks = true` in die `config.toml` geschrieben. Dazu Git-Hooks: Checkpoints entstehen, wenn du oder der Agent committen; die Session-Metadaten möchte ich entweder auf einem child-repo haben oder falls wir diese kombination nicht haben direkt im repo. Das Verhalten soll an der Stelle absolut gleich sein. M5.0 docs: Plan.md — M5 von Transkript-Parsing auf Hooks umgestellt (ADR-0003) M5.1 feat(core): Lineage, Turn.parent/at, ToolCall.effect, Vec<Edge> (additiv) M5.2 feat(capture): JournalEvent + Journal (Datei pro Event, 0600, fsck-fähig) M5.3 feat(cli): minds hook — stdin lesen, anhängen, Exit 0, immer M5.4 feat(capture): Normalisierer Claude Code (SessionStart/Prompt/Tool*/Stop/Subagent*) M5.5 feat(capture): Secretfile-Mauer bei PreToolUse M5.6 feat(capture): Journal + Transkript → Vec<Session> (Turns, Usage, Intent) M5.7 feat(capture): Kanten — Subagent (Observed), Artefakt-Hash, Commit M5.8 feat(cli): minds enable --agent claude-code (settings.json mergen, idempotent) M5.9 test(capture): Fixtures — single, subagent, zwei Agents parallel
