1//! Intent zuerst — die Verdichtung einer Session auf eine Zeile.
2//!
3//! Der Reviewer soll lesen, *was verlangt wurde*, bevor er den Diff sieht. Dafür
4//! braucht die Übersicht pro Session eine Überschrift, und die entsteht hier.
5//!
6//! # Deterministisch extrahiert, nicht generiert — null Tokens
7//!
8//! Es gibt kein Modell in diesem Pfad. Die Überschrift ist die erste sinnvolle
9//! Zeile des ersten Prompts, an einer Wortgrenze gekürzt. Das ist weniger schön
10//! als eine LLM-Zusammenfassung und dafür: kostenlos, offline, sofort — und bei
11//! gleicher Session **immer identisch**. Der Plan hält den Summary-Pfad mit
12//! Modell bewusst für nach v0.1 zurück (M8, mit Caching über die `SessionId`);
13//! bis dahin ist das hier die ganze Wahrheit.
14//!
15//! Wer den vollen Prompt will, klickt die Session an — die Verdichtung ersetzt
16//! ihn nicht, sie führt zu ihm hin.
17
18use minds_core::{Session, SessionId};

20/// Wie lang eine Überschrift höchstens wird, bevor gekürzt wird.
21pub const HEADLINE_MAX: usize = 90;
22
23/// Eine Session, verdichtet auf das, was in eine Übersichtszeile passt.
24#[derive(Debug, Clone, PartialEq, Eq)]
25pub struct Summary {
26 /// Die Session, auf die sich das bezieht.
27 pub id: SessionId,
28 /// Worum es ging, in einer Zeile.
29 pub headline: String,
30 /// Wer es tat: `agent · modell`.
31 pub actor: String,
32 /// Wie viele Dateien die Session hervorgebracht hat.
33 pub files: usize,
34 /// Wie viele Constraints erfasst sind.
35 pub constraints: usize,
36 /// Wie viele verworfene Pfade erfasst sind.
37 pub discarded: usize,
38 /// Token ein/aus.
39 pub input_tokens: u64,
40 /// Token aus.
41 pub output_tokens: u64,
42}
43
44impl Summary {
45 /// Verdichtet eine Session.
46 pub fn of(id: SessionId, session: &Session) -> Self {
47 Self {
48 id,
49 headline: headline(&session.intent.request, HEADLINE_MAX),
50 actor: format!("{} · {}", session.agent.name, session.model.id),
51 files: session.produced.files.len(),
52 constraints: session.intent.constraints.len(),
53 discarded: session.intent.discarded.len(),
54 input_tokens: session.usage.input_tokens,
55 output_tokens: session.usage.output_tokens,
56 }
57 }
58}
59
60/// Die erste sinnvolle Zeile von `request`, auf höchstens `max` Zeichen an einer
61/// Wortgrenze gekürzt.
62///
63/// Leerer oder nur aus Leerraum bestehender Text ergibt einen ehrlichen
64/// Platzhalter statt einer leeren Überschrift — der Reader behauptet nie, es
65/// gäbe einen Prompt, wo keiner erfasst wurde.
66pub fn headline(request: &str, max: usize) -> String {
67 let first = request
68 .lines()
69 .map(str::trim)
70 .find(|line| !line.is_empty())
71 .unwrap_or("");
72
73 if first.is_empty() {
74 return "(kein Prompt erfasst)".to_string();
75 }
76
77 // `chars().count()` statt `len()`: gekürzt wird nach Zeichen, nicht nach
78 // Bytes — sonst zerschnitte ein Umlaut die Ausgabe.
79 if first.chars().count() <= max {
80 return first.to_string();
81 }
82
83 let cut: String = first.chars().take(max).collect();
84 let trimmed = match cut.rsplit_once(' ') {
85 // Nur an der Wortgrenze schneiden, wenn dabei noch etwas übrig bleibt.
86 Some((head, _)) if head.chars().count() >= max / 2 => head,
87 _ => cut.trim_end(),
88 };
89 format!("{}…", trimmed.trim_end())
90}

Das ist der entscheidende Unterschied. Minds soll auch Hooks installieren im Agenten selbst: Claude Code über `.claude/settings.json`, Codex über `.codex/hooks.json`, Cursor über `.cursor/hooks.json`, Gemini über `.gemini/settings.json`, OpenCode über ein TypeScript-Plugin. Bei Codex wird zusätzlich `codex_hooks = true` in die `config.toml` geschrieben. Dazu Git-Hooks: Checkpoints entstehen, wenn du oder der Agent committen; die Session-Metadaten möchte ich entweder auf einem child-repo haben oder falls wir diese kombination nicht haben direkt im repo. Das Verhalten soll an der Stelle absolut gleich sein.
