1//! Die fail-closed-Garantie auf Session-Ebene — und der Audit, der sie belegt.
2//!
3//! [`crate::pipeline`] bereinigt *einen Text* und ist dabei bewusst infallibel:
4//! Ein String lässt sich immer bereinigen. Diese Ebene beantwortet die andere
5//! Hälfte der Frage — **wann darf eine ganze [`Session`] als redigiert gelten?**
6//!
7//! Antwort in einem Satz: nur dann, wenn jedes Textfeld des Envelopes
8//! nachweislich durch die Pipeline gelaufen ist und dabei nichts schiefging.
9//! Alles andere ist ein Fehler, kein halbes Ergebnis.
10//!
11//! # Drei Bauformen, die fail-closed *erzwingen* statt darum zu bitten
12//!
13//! **1. Die Session wird verbraucht, nicht geliehen.**
14//! [`RedactionPipeline::redact_session`] nimmt die [`Session`] *by value* und
15//! gibt im Fehlerfall **nichts** zurück. Die naheliegende Signatur
16//! `fn redact_session(&self, s: &mut Session) -> Result<..>` wäre die
17//! fail-open-Variante: Bricht sie in der Mitte ab, hält der Aufrufer eine halb
18//! bereinigte Session in der Hand — und genau die wird dann doch gespeichert.
19//! Was es nicht gibt, kann nicht versehentlich benutzt werden.
20//!
21//! **2. Der Nachweis ist ein Typ.** Erfolg liefert [`RedactedSession`], und
22//! dieser Typ hat keinen öffentlichen Konstruktor. Wer ihn hat, hat ihn von der
23//! Pipeline bekommen. `minds-store` (M4) sollte deshalb `&RedactedSession`
24//! entgegennehmen und nicht `&Session`: Eine ungeredactete Session zu speichern
25//! ist dann kein Policy-Verstoß mehr, sondern ein Compile-Fehler. Das Flag
26//! `redaction.applied` im Envelope bleibt trotzdem nötig — es überlebt die
27//! Serialisierung, der Typ nicht.
28//!
29//! **3. Ein neues Envelope-Feld bricht den Build.**
30//! [`RedactionPipeline::redact_session`] zerlegt [`Session`], [`Intent`],
31//! [`Turn`], [`ToolCall`], [`Agent`], [`Model`] und [`Produced`] per
32//! *exhaustivem* Destructuring. Wächst das Schema um ein Feld, kompiliert genau
33//! diese Funktion nicht mehr — der gewollte Zwang, für jedes neue Feld zu
34//! entscheiden, ob es gescannt werden muss. Die Alternative (Feld für Feld über
35//! `&mut` anfassen) hätte still weitergebaut und das neue Feld ungeprüft
36//! durchgelassen.
37//!
38//! # Welche Felder gescannt werden: alle
39//!
40//! Jeder [`String`] im Envelope geht durch die Pipeline — auch `agent.name`,
41//! `model.id` und `produced.commit_hint`, bei denen „da kann nichts drinstehen"
42//! naheliegt. Die Ausnahme-Liste ist bewusst leer, aus zwei Gründen: Sie wäre
43//! eine Annahme über *fremde* Adapter (M5 schreibt diese Felder), und sie
44//! veraltet lautlos. Der Preis ist praktisch null — kein eingebauter Detektor
45//! feuert auf `claude-opus-4` oder einen 40-stelligen Hex-SHA (Hex trägt
46//! höchstens 4 bit/Zeichen und bleibt damit unter der Entropieschwelle). Trifft
47//! eine *Denylist* dort, war das eine bewusste Konfigurationsentscheidung.
48//!
49//! # Was als Fehler gilt
50//!
51//! - [`RedactionError::NoDetectors`] — eine Pipeline ohne Detektoren würde
52//! jeden Text unverändert durchreichen und ihn anschließend als „redigiert"
53//! ausweisen. Das ist fail-open im Erfolgs-Gewand und deshalb der wichtigste
54//! der vier Fehler.
55//! - [`RedactionError::AlreadyRedacted`] — eine bereits markierte Session
56//! erneut zu redigieren fände nichts mehr und würde die echten Zähler mit
57//! Nullen überschreiben. Der Audit wäre danach eine Lüge.
58//! - [`RedactionError::InvalidFinding`] — ein Detektor hat den
59//! [`Finding`](crate::Finding)-Vertrag verletzt, sein Fund musste verworfen
60//! werden, und der zugehörige Text steht möglicherweise noch da. Die
61//! Pipeline-Doku verweist für diesen Fall auf „den fail-closed-Commit" — hier
62//! ist er.
63//! - [`RedactionError::Unstable`] — siehe unten.
64//!
65//! # Der Verifikationslauf
66//!
67//! Für jedes Feld, das sich verändert hat, läuft die Pipeline ein zweites Mal
68//! über das *Ergebnis*. Verändert sie es erneut, hat der erste Lauf etwas
69//! stehen lassen; die Session wird verworfen. Felder, die der erste Lauf nicht
70//! angefasst hat, brauchen keinen zweiten — die Pipeline ist deterministisch,
71//! gleiche Eingabe hieße gleiches Ergebnis.
72//!
73//! Verglichen wird der **Text, nicht der Zähler** — das ist keine Schlamperei,
74//! sondern nötig: Aus `DB_PASSWORD=hunter2` wird
75//! `DB_PASSWORD=[redacted:secret]`, und im zweiten Lauf trifft
76//! [`KeyValueRedactor`](crate::KeyValueRedactor) den Platzhalter erneut als
77//! Wert hinter `PASSWORD=`. Er ersetzt ihn durch sich selbst: Zähler +1, Text
78//! unverändert. Ein Zähler-Vergleich würde hier falschen Alarm schlagen, der
79//! Text-Vergleich nicht.
80//!
81//! # Der Audit trägt Zähler und Ortsangaben — nie Werte
82//!
83//! [`RedactionAudit`] kennt drei Sorten Information: wie viele Felder geprüft
84//! wurden, wie viel je Kategorie entfernt wurde, und **wo** — als
85//! [`Field`]-Pfad wie `turns[3].tool_calls[0].arguments`. Ein Ort ist keine
86//! Information über den entfernten Wert; er ist genau das, was ein Reviewer
87//! braucht („warum ist der Record hier löchrig?"), ohne dass irgendwo ein
88//! Geheimnis zwischengespeichert wird. Der Typ enthält schlicht keine
89//! Zeichenkette aus dem Eingabetext — die Zusage ist strukturell, nicht
90//! disziplinarisch.
91//!
92//! Ins Envelope wandert davon nur die Summe ([`minds_core::Redaction`]); die
93//! Ortsangaben bleiben im Prozess und sind für die CLI-Ausgabe von
94//! `minds capture` gedacht.

109/// Warum eine Session **nicht** als redigiert gelten darf.
110///
111/// Jede Variante bedeutet dasselbe für den Aufrufer: Es gibt keine Session zu
112/// speichern. Capture bricht ab.
113#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
114pub enum RedactionError {
115 /// Die Pipeline enthält keinen einzigen Detektor.
116 #[error(
117 "Redaction-Policy ohne Detektoren: eine leere Pipeline ließe jeden Text \
118 unverändert durch und würde ihn trotzdem als redigiert ausweisen"
119 )]
120 NoDetectors,
121
122 /// Die Session trägt bereits `redaction.applied == true`.
123 #[error(
124 "Session ist bereits als redigiert markiert; ein zweiter Lauf fände \
125 nichts mehr und würde den Audit des ersten überschreiben"
126 )]
127 AlreadyRedacted,
128
129 /// Ein Detektor hat einen vertragswidrigen Span geliefert (leer,
130 /// out-of-bounds oder nicht auf einer UTF-8-Grenze). Der Fund wurde
131 /// verworfen — der Text an dieser Stelle ist damit möglicherweise
132 /// ungeschwärzt.
133 #[error(
134 "Detektor-Vertrag verletzt: {count} ungültige Fund-Span(s) in {field} \
135 mussten verworfen werden — der zugehörige Text ist möglicherweise \
136 ungeschwärzt geblieben"
137 )]
138 InvalidFinding {
139 /// Wo im Envelope.
140 field: Field,
141 /// Wie viele Funde verworfen wurden.
142 count: u32,
143 },
144
145 /// Der Verifikationslauf hat den bereits bereinigten Text erneut verändert
146 /// — die Bereinigung erreicht keinen Fixpunkt, der erste Lauf hat also
147 /// etwas stehen lassen.
148 #[error(
149 "Redaction in {field} erreicht keinen Fixpunkt: ein zweiter Durchlauf \
150 verändert den bereits bereinigten Text erneut"
151 )]
152 Unstable {
153 /// Wo im Envelope.
154 field: Field,
155 },
156}

256/// Nachweis eines Session-weiten Redaction-Laufs: **nur Zähler und
257/// Ortsangaben, niemals Werte.**
258///
259/// Der Typ enthält keine einzige aus dem Eingabetext stammende Zeichenkette —
260/// weder [`Debug`] noch [`Display`](fmt::Display) können deshalb ein Geheimnis
261/// ausgeben, egal wie sie aufgerufen werden.
262#[derive(Debug, Clone, Default, PartialEq, Eq)]
263pub struct RedactionAudit {
264 counts: RedactionCounts,
265 fields_scanned: usize,
266 sites: Vec<AuditSite>,
267}
268
269impl RedactionAudit {
270 /// Verbucht ein geprüftes Feld.
271 fn record(&mut self, field: Field, counts: RedactionCounts) {
272 self.fields_scanned += 1;
273 if counts == RedactionCounts::default() {
274 return;
275 }
276 self.counts.secrets = self.counts.secrets.saturating_add(counts.secrets);
277 self.counts.pii = self.counts.pii.saturating_add(counts.pii);
278 self.sites.push(AuditSite { field, counts });
279 }
280
281 /// Summe über alle Felder — genau das, was als Zähler in
282 /// [`minds_core::Redaction`] ins Envelope geht.
283 pub fn counts(&self) -> RedactionCounts {
284 self.counts
285 }
286
287 /// Wie viele Textfelder geprüft wurden. Die interessante Zahl ist nicht,
288 /// wie viel gefunden wurde, sondern dass *nichts* ungeprüft blieb.
289 pub fn fields_scanned(&self) -> usize {
290 self.fields_scanned
291 }
292
293 /// Wie viele Felder tatsächlich verändert wurden.
294 pub fn fields_changed(&self) -> usize {
295 self.sites.len()
296 }
297
298 /// Die veränderten Felder mit ihren Zählern, in Envelope-Reihenfolge.
299 pub fn sites(&self) -> &[AuditSite] {
300 &self.sites
301 }
302
303 /// `true`, wenn nichts gefunden wurde. **Nicht** dasselbe wie „nicht
304 /// gelaufen" — ein sauberer Lauf ist der Normalfall.
305 pub fn is_clean(&self) -> bool {
306 self.counts == RedactionCounts::default()
307 }
308}

368impl RedactionPipeline {
369 /// Bereinigt **jedes** Textfeld einer [`Session`] und liefert den Nachweis.
370 ///
371 /// Erfolg heißt: alle Felder gescannt, kein Detektor-Vertrag verletzt,
372 /// jedes veränderte Feld verifiziert, `redaction.applied` gesetzt und die
373 /// Zähler eingetragen. Jeder Fehler heißt: **es gibt keine Session** — die
374 /// übergebene ist verbraucht, eine bereinigte entsteht nicht. Genau das ist
375 /// die fail-closed-Garantie (Architektur-Prinzip 3 im Plan).
376 ///
377 /// Was diese Funktion *nicht* prüfen kann, ist die Qualität der Policy: Eine
378 /// Pipeline, die nur E-Mail-Adressen kennt, ist nicht leer und läuft durch.
379 /// Die überprüfbare Untergrenze ist „mindestens ein Detektor"; darüber
380 /// entscheidet [`RedactionConfig`](crate::RedactionConfig), deren Default
381 /// alle eingebauten Detektoren anschaltet.
382 ///
383 /// ```
384 /// use minds_core::{Agent, Intent, Model, Role, Session, Turn};
385 /// use minds_redact::RedactionConfig;
386 ///
387 /// let mut session = Session::new(
388 /// Agent { name: "claude-code".into(), version: "1.0.0".into() },
389 /// Model { provider: "anthropic".into(), id: "claude-opus-4".into() },
390 /// Intent::default(),
391 /// );
392 /// session.turns.push(Turn {
393 /// role: Role::User,
394 /// text: "setz DB_PASSWORD=hunter2".into(),
395 /// tool_calls: Vec::new(),
396 /// parent: None,
397 /// at: None,
398 /// });
399 ///
400 /// let pipeline = RedactionConfig::default().pipeline().unwrap();
401 /// let redacted = pipeline.redact_session(session).unwrap();
402 ///
403 /// assert!(redacted.session().redaction.applied);
404 /// assert_eq!(redacted.audit().counts().secrets, 1);
405 /// assert!(!redacted.session().turns[0].text.contains("hunter2"));
406 /// ```
407 pub fn redact_session(&self, session: Session) -> Result<RedactedSession, RedactionError> {
408 if self.is_empty() {
409 return Err(RedactionError::NoDetectors);
410 }
411 if session.redaction.applied {
412 return Err(RedactionError::AlreadyRedacted);
413 }
414
415 // Exhaustives Destructuring: Wächst das Envelope um ein Feld, bricht
416 // *diese* Zeile den Build. Gewollt — siehe Modul-Doku.
417 let Session {
418 schema_version,
419 agent,
420 model,
421 intent,
422 turns,
423 usage,
424 produced,
425 // `lineage.cwd` und `effect.path` (unten) tragen fast immer einen
426 // Home-Pfad und damit einen Benutzernamen — PII. Sie laufen deshalb
427 // durch dieselbe Pipeline wie jedes andere Textfeld. `edges` dagegen
428 // hält nur Agentnamen, UUIDs und Commit-Hashes: nichts Sensibles,
429 // deshalb unverändert durch.
430 lineage,
431 edges,
432 // Wird unten aus dem Audit neu gesetzt; der alte Wert ist per
433 // `AlreadyRedacted`-Prüfung ohnehin der Default.
434 redaction: _,
435 } = session;
436
437 let mut audit = RedactionAudit::default();
438
439 let Agent { name, version } = agent;
440 let agent = Agent {
441 name: self.redact_field(Field::AgentName, name, &mut audit)?,
442 version: self.redact_field(Field::AgentVersion, version, &mut audit)?,
443 };
444
445 let Model { provider, id } = model;
446 let model = Model {
447 provider: self.redact_field(Field::ModelProvider, provider, &mut audit)?,
448 id: self.redact_field(Field::ModelId, id, &mut audit)?,
449 };
450
451 let Intent {
452 request,
453 constraints,
454 discarded,
455 } = intent;
456 let intent = Intent {
457 request: self.redact_field(Field::IntentRequest, request, &mut audit)?,
458 constraints: self.redact_list(constraints, Field::IntentConstraint, &mut audit)?,
459 discarded: self.redact_list(discarded, Field::IntentDiscarded, &mut audit)?,
460 };
461
462 let mut redacted_turns = Vec::with_capacity(turns.len());
463 for (turn_index, turn) in turns.into_iter().enumerate() {
464 let Turn {
465 role,
466 text,
467 tool_calls,
468 parent,
469 at,
470 } = turn;
471
472 let text = self.redact_field(Field::TurnText(turn_index), text, &mut audit)?;
473
474 let mut redacted_calls = Vec::with_capacity(tool_calls.len());
475 for (call_index, call) in tool_calls.into_iter().enumerate() {
476 let ToolCall {
477 name,
478 arguments,
479 effect,
480 } = call;
481 let effect = self.redact_effect(effect, turn_index, call_index, &mut audit)?;
482 redacted_calls.push(ToolCall {
483 effect,
484 // Der Tool-*Name* ist Vokabular des Agents und trägt
485 // normalerweise nichts Sensibles — normalerweise. Er kostet
486 // einen Scan über zehn Zeichen; die Ausnahme wäre teurer.
487 name: self.redact_field(
488 Field::ToolCallName {
489 turn: turn_index,
490 call: call_index,
491 },
492 name,
493 &mut audit,
494 )?,
495 arguments: self.redact_field(
496 Field::ToolCallArguments {
497 turn: turn_index,
498 call: call_index,
499 },
500 arguments,
501 &mut audit,
502 )?,
503 });
504 }
505
506 redacted_turns.push(Turn {
507 role,
508 text,
509 tool_calls: redacted_calls,
510 parent,
511 at,
512 });
513 }
514
515 let Produced { commit_hint, files } = produced;
516 let commit_hint = commit_hint
517 .map(|hint| self.redact_field(Field::ProducedCommitHint, hint, &mut audit))
518 .transpose()?;
519 let files = self.redact_list(files, Field::ProducedFile, &mut audit)?;
520 let produced = Produced { commit_hint, files };
521
522 let lineage = self.redact_lineage(lineage, &mut audit)?;
523
524 let session = Session {
525 schema_version,
526 agent,
527 model,
528 intent,
529 turns: redacted_turns,
530 usage,
531 produced,
532 lineage,
533 edges,
534 redaction: Redaction {
535 applied: true,
536 counts: audit.counts(),
537 },
538 };
539
540 Ok(RedactedSession { session, audit })
541 }

543 /// Bereinigt ein einzelnes Feld, verifiziert das Ergebnis und verbucht es.
544 fn redact_field(
545 &self,
546 field: Field,
547 text: String,
548 audit: &mut RedactionAudit,
549 ) -> Result<String, RedactionError> {
550 let first = self.redact(&text);
551 if first.invalid_findings > 0 {
552 return Err(RedactionError::InvalidFinding {
553 field,
554 count: first.invalid_findings,
555 });
556 }
557
558 // Verifikation nur für Felder, die sich verändert haben: Blieb der Text
559 // gleich, liefert ein zweiter Lauf über denselben Text zwangsläufig
560 // dasselbe Ergebnis (die Pipeline ist deterministisch).
561 if first.text != text {
562 let second = self.redact(&first.text);
563 if second.invalid_findings > 0 {
564 return Err(RedactionError::InvalidFinding {
565 field,
566 count: second.invalid_findings,
567 });
568 }
569 // Verglichen wird der Text, nicht der Zähler — siehe Modul-Doku
570 // (Platzhalter können erneut treffen, ohne etwas zu verändern).
571 if second.text != first.text {
572 return Err(RedactionError::Unstable { field });
573 }
574 }
575
576 audit.record(field, first.counts);
577 Ok(first.text)
578 }

580 /// [`redact_field`](Self::redact_field) über eine Liste, mit Index im
581 /// Feld-Pfad.
582 fn redact_list(
583 &self,
584 items: Vec<String>,
585 field_at: impl Fn(usize) -> Field,
586 audit: &mut RedactionAudit,
587 ) -> Result<Vec<String>, RedactionError> {
588 let mut out = Vec::with_capacity(items.len());
589 for (index, item) in items.into_iter().enumerate() {

591 }

595 /// Redigiert den Pfad eines [`Effect`]; `kind` und `content` bleiben.
596 ///
597 /// `content` ist ein blake3-Hash (Hex, geringe Entropie) und trägt nichts
598 /// Sensibles — der [`HighEntropyRedactor`](crate::HighEntropyRedactor) fasst
599 /// ihn ohnehin nicht an. Redigiert wird nur der Pfad, der bei absoluten
600 /// Angaben einen Benutzernamen enthalten kann.
601 fn redact_effect(
602 &self,
603 effect: Option<Effect>,
604 turn: usize,
605 call: usize,
606 audit: &mut RedactionAudit,
607 ) -> Result<Option<Effect>, RedactionError> {
608 let Some(Effect {
609 kind,
610 path,
611 content,
612 }) = effect
613 else {
614 return Ok(None);
615 };
616 let path = match path {
