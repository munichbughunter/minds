1//! Korpus-Tests: die Redaction gegen realistischen Text, in beide Richtungen.
2//!
3//! Die Unit-Tests in den Detektor-Modulen prüfen je *ein* Muster. Dieser Korpus
4//! prüft die **zusammengesetzte Default-Policy** gegen Text, wie er in
5//! Agent-Transkripten tatsächlich vorkommt — und er prüft beide Fehlerrichtungen,
6//! weil nur eine davon offensichtlich ist:
7//!
8//! - **[`MUST_REDACT`] — False Negatives.** Was hier durchrutscht, ist ein Leck.
9//! Der teure Fehler, und der, an den alle denken.
10//! - **[`MUST_SURVIVE`] — False Positives.** Was hier fälschlich verschwindet,
11//! zerstört den Record. Ein Reader, der statt des Prompts eine Reihe von
12//! Platzhaltern zeigt, ist wertlos — dann kann man Minds auch weglassen. Diese
13//! Hälfte ist die schwierigere und deshalb die längere Tabelle.
14//!
15//! Dazu zwei Tabellen, die keine Prüfung, sondern eine **Festschreibung** sind:
16//! [`ACCEPTED_OVER_REDACTION`] hält fest, wo wir bewusst zu viel schwärzen, und
17//! [`DOCUMENTED_GAPS`], wo bewusst zu wenig. Beide Tabellen schlagen an, sobald
18//! sich das Verhalten ändert — auch zum Besseren. Genau das ist der Zweck: Eine
19//! stillschweigende Verschiebung der Trennlinie soll es nicht geben.
20//!
21//! # Zwei Regeln für dieses Verzeichnis
22//!
23//! 1. **Nie ein echtes Geheimnis als Fixture.** Alle Token hier sind
24//! synthetisch, alle Adressen liegen in `example.*`/`.test`. Die Datei liegt
25//! im Repo — dieselbe Regel wie für die Allowlist.
26//! 2. **Ein Fixture, das rot wird, ist erst einmal eine Frage, keine Antwort.**
27//! Sie lautet: Ist die neue Trennlinie besser? Wenn ja, wandert der Eintrag
28//! in die andere Tabelle, statt gelöscht zu werden.
29//!
30//! Der Korpus prüft die *Detektoren* (Schicht 2). Die Mauer davor
31//! (Zugangsdaten-Dateien, Schicht 1) und die Garantie dahinter
32//! (`redact_session`, Schicht 3) haben je einen eigenen Test am Ende.
33

419/// Die Policy, die ein Repo ohne eigene Config bekommt.
420fn policy() -> RedactionPipeline {
421 RedactionConfig::default()
422 .pipeline()
423 .expect("Default-Policy muss bauen")
424}

426/// Sammelt alle Beanstandungen und meldet sie **gemeinsam**.
427///
428/// Ein Korpus, der beim ersten Treffer abbricht, verwandelt „drei Fixtures sind
429/// rot" in drei Testläufe. Der Bericht am Ende zeigt das ganze Bild.
430#[derive(Default)]
431struct Report {
432 problems: Vec<String>,
433}
434
435impl Report {
436 fn note(&mut self, problem: String) {
437 self.problems.push(problem);
438 }
439
440 fn finish(self, headline: &str) {
441 assert!(
442 self.problems.is_empty(),
443 "{headline} — {} Beanstandung(en):\n\n{}\n",
444 self.problems.len(),
445 self.problems.join("\n")
446 );
447 }
448}

450/// Der Text eines [`MUST_SURVIVE`]-Eintrags, über seinen Bezeichner.
451fn survivor(id: &str) -> &'static str {
452 MUST_SURVIVE
453 .iter()
454 .find(|(fixture, _)| *fixture == id)
455 .map(|(_, text)| *text)
456 .unwrap_or_else(|| panic!("kein MUST_SURVIVE-Fixture mit id {id:?}"))
457}
458
459/// Setzt einen Text in eine Mehrbyte-Umgebung. Die Detektoren rechnen in Bytes;
460/// ein Fund, dessen Grenzen nicht auf einer Zeichengrenze liegen, würde beim
461/// Ersetzen paniken oder als Vertragsverstoß gezählt.
462fn in_multibyte_context(text: &str) -> String {
463 format!("Präfix äöü 🦀\n{text}\n🦀 Süffix")
464}

470#[test]
471fn no_corpus_fixture_leaks() {
472 let pipeline = policy();
473 let mut report = Report::default();
474
475 for case in must_redact() {
476 let out = pipeline.redact(&case.text);
477
478 for needle in case.gone {
479 if out.text.contains(needle) {
480 report.note(format!(
481 "{}: {needle:?} steht noch im Ergebnis:\n {}",
482 case.id, out.text
483 ));
484 }
485 }
486 if out.counts == Default::default() {
487 report.note(format!("{}: kein einziger Fund gezählt", case.id));
488 }
489 }
490
491 report.finish("Der Korpus leckt");
492}

Absicht

Ich möchte M5 so umbauen, dass wir es genauso machen wie entire! Mit dem Hook-Ansatz. Wir bleiben erst einmal bei der Rust implementierung. Diese ist effizienter. Das Verhalten soll an der Stelle absolut gleich sein.
